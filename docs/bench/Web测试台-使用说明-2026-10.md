# Web 测试台使用说明（2026-10）

> 给开发者模式用的宽屏测试界面：查看用例输入 / 提示词、批量跑模型、逐个打分。
> 独立于 PS 面板运行，但读写的是同一份插件数据。

---

## 1. 为什么单独做 Web

PS 面板宽度只有 280–420px，塞不下「输入 + 提示词 + 多模型结果网格」。Web 测试台在浏览器里用宽屏展示：

- 左侧用例列表，右侧提示词与输入素材；
- 结果网格 3–5 列，每个模型一张卡，可单独打 1–5 星、写备注、设基准；
- 运行与评分直接写回插件的数据目录，插件面板重新打开就能看到。

---

## 2. 启动（三种方式）

### 方式一：双击（推荐）

- macOS：双击项目根目录的 **`启动Web测试台.command`**
- Windows：双击 **`启动Web测试台.bat`**

会自动找到 Node、启动服务并打开浏览器；关掉终端窗口即停止服务。

> macOS 首次双击若被系统拦截：右键 → 打开 → 仍要打开。

### 方式二：npm

```bash
cd bench
npm run web          # 启动并自动打开浏览器
```

### 方式三：手动

```bash
node bench/web-server.mjs --open
```

默认端口 7788；被占用会自动尝试 7789、7790…，终端会打印实际地址。

常用参数：

| 参数 | 说明 |
|---|---|
| `--port 7788` | 端口，默认 7788 |
| `--data <dir>` | 指定数据目录（默认自动探测插件 PluginData） |
| `--config <file>` | 指定配置文件（默认 `bench/config.json`） |
| `--open` | 启动后自动打开浏览器 |

---

## 3. 配置 API Key

首次启动后，页面「运行模型」区域会直接出现输入框：粘贴 Key、点「保存」即可，只写入本机 `bench/config.json`，不会上传。

也可以手动配置：

方式一：编辑 `bench/config.json`

```json
{
  "providers": {
    "grsai": {
      "apiKey": "sk-你的Key"
    }
  }
}
```

方式二：启动时带环境变量

```bash
GRSAI_API_KEY=sk-你的Key npm run web
```

页面右上角显示「Key 已配置 / 未配置」；未配置时运行按钮禁用。

## 4. 数据从哪来

自动探测（macOS）：

```
~/Library/Application Support/Adobe/UXP/PluginsStorage/PHSP/<ver>/External/
  com.psspark.ps.assistant/PluginData/dev/bench/
```

Windows：

```
%APPDATA%/Adobe/UXP/PluginsStorage/PHSP/<ver>/External/
  com.psspark.ps.assistant/PluginData/dev/bench/
```

结构：

```
bench/
  index.json
  cases/<caseId>/
    case.json
    input.png        # 实际可能是 JPEG，按字节识别
    mask.png         # 有选区时才有
    assets/          # 拼合/参考图类才有
    runs/<runId>/
      output.png
      meta.json      # 模型/耗时/尺寸/体积/评分/备注/错误
```

插件里「基准 ▸ 冻结当前画面并运行」创建用例；Web 里只负责查看、运行与打分。

## 5. 页面功能

| 区域 | 能做什么 |
|---|---|
| 用例列表 | 切换用例；显示运行数、是否含蒙版/资产 |
| 用例信息 | 功能/分支、创建时间、输入尺寸、提示词字数 |
| 输入素材 | 输入画面、蒙版、资产缩略图，点击放大 |
| 提示词 | 冻结时的最终提示词全文，可选中复制 |
| 运行模型 | 按系列分组多选；云端模型并发、本地 ComfyUI 串行；支持「只选未跑」 |
| 结果 | 每个模型一张卡：结果图、耗时、尺寸、体积、星级、备注、设基准 |
| 删除用例 | 连同全部结果一起删除，不可恢复 |

运行与评分写回磁盘；插件面板需要**刷新/重开工作台**才能看到最新结果。

### 并发策略

- **云端 API 模型**：并发执行，并发数取 `bench/config.json` 的 `concurrency`（默认 2，范围 1–6）。
- **本地 ComfyUI**：固定串行，避免多个工作流同时抢显存；与 API 并发互不影响。
- 进度按「完成数 / 总数」显示，运行中会列出当前并发的模型。
- 「只选未跑」会跳过已有成功结果的模型，适合增量复测。
- 每个模型独立超时、独立落盘，单个失败不会中断其他模型。

### Web 端使用本地 ComfyUI（多预设）

`bench/config.json` 写 `comfy.presets`，每条对应一台机器/一条工作流：

```json
"comfy": {
  "presets": [
    {
      "id": "mac-klein",
      "name": "Klein 4B（Mac）",
      "url": "http://127.0.0.1:8188",
      "workflow": { "1": { "class_type": "..." } },
      "promptNode": "4",
      "caps": ["t2i"]
    },
    {
      "id": "win-inpaint",
      "name": "SDXL 重绘（Win）",
      "url": "http://192.168.1.9:8188",
      "workflow": "{ ...API 格式字符串也可以... }",
      "caps": ["t2i", "i2i", "inpaint"]
    }
  ]
}
```

模型列表里每条预设一个选项：`本地 · Klein 4B（Mac）`，串行执行（显存只够跑一条）。
旧配置（单个 `comfy.url` + `comfy.workflow`）仍兼容，自动视为 `id=default` 的预设。

**按能力放行**：`caps` 与用例功能对应——
文生图用例要 `t2i`、相似图要 `i2i`、带蒙版要 `inpaint`、拆图要 `segment`。
不满足的预设会说明「未声明 X 能力」，接口直接返回 400，不会静默跑出一张与输入无关的图。

### 跨机跑同一份用例
侧栏底部两个按钮：

- **导出用例包** → 下载一个 JSON（含输入图/蒙版/资产 base64、提示词、参数、已跑出的可复现参数）；
- **导入用例包** → 另一台机器导入后得到一条新用例，提示词与素材完全一致。

复现细节：用例 `params.seed` 填了就固定用这个 seed，没填则运行时随机并记录实际值。
结果卡的 `meta.provenance` 记了 `seed / 工作流指纹(workflowHash) / 采样参数 / 模型文件名 / 预设与地址`，
卡片上直接显示 `seed … · wf …`，鼠标悬停看模型文件。两台机器对比时先对这两行，
不一致说明工作流或模型不是同一份，别急着比画质。- 想批量测本地模型，先在 PS 里冻结一条**文生图**用例。

「全选」「只选未跑」也会跳过灰态的本地选项。

## 6. 选区修改、图像拼合怎么测

### 6.1 选区类（局部重绘 / 擦除 / 内容修图 / 换色 / 高清修复 / 线稿上色）

冻结时如果 PS 里**有选区**，插件会额外导出 `mask.png`：

- 白 = 选区（允许修改）；
- 黑 = 选区外（保持不变）；
- 尺寸与输入图一致（插件会按输入图缩放）。

Web 运行到支持蒙版的模型（gpt-image 系列，走 edits）时会带上 `mask`。  
选中「需要选区」的功能但当前没有选区时，用例会带一条警告，按整图测试。

> **nano-banana 系列不传 mask**：与插件线上行为一致（该族未文档化蒙版能力，靠提示词定位）。要测蒙版效果，请选 gpt-image 系列。

### 6.2 拼合 / 参考图类（原位合成 / 艺术融合 / 图像融合 / 商品图）

冻结时如果 PS 里**选中了素材图层**，插件会把选中图层合并成一张「画布对齐、透明背景」的资产图，写入 `assets/`。

- 底图 = `input.png`（当前画面）；
- 资产 = `assets/asset_1.png`；
- Web 运行 nano 系列时把两张一起发给统一端点（`images[]`）；
- gpt-image 的 edits 端点只接受单图，会只用底图（与插件线上一致）。

**原位合成怎么摆**：先在 PS 里把素材拖到目标位置、选中素材图层，再冻结。这样底图与资产坐标一致，测试的是「模型能不能自然融合」，而不是「能不能摆对位置」。

## 7. Windows 端

支持。`bench/web-server.mjs` 是纯 Node，前端是浏览器页面，不依赖 macOS。

启动：

1. 安装 Node.js 18+（`node -v` 确认）；
2. 安装开发构建 `dist/dev/ps-spark-dev-win.zip`；
3. 双击项目根目录的 **`启动Web测试台.bat`**，或命令行：

```
node bench\web-server.mjs --open
```

数据目录自动探测：

```
%APPDATA%\Adobe\UXP\PluginsStorage\PHSP\<ver>\External\
  com.psspark.ps.assistant\PluginData\dev\bench
```

找不到时手动指定：

```
node bench\web-server.mjs --data "C:\Users\你\AppData\Roaming\Adobe\UXP\PluginsStorage\PHSP\26\External\com.psspark.ps.assistant\PluginData\dev\bench"
```

注意：

- 必须是**开发构建**，发布版没有 `dev/bench`；
- 只监听 `127.0.0.1`，不会触发防火墙入站提示；
- 自动打开浏览器用 `explorer.exe`，没打开就手动访问终端打印的地址；
- 本地 ComfyUI 地址同样是 `http://127.0.0.1:8188`。

未在 Windows 实机验证的点：UXP 版本目录差异、`%APPDATA%` 被重定向、bat 中文编码。遇到问题先看终端打印的「数据」路径。

## 8. 已知限制

- Web 运行使用 benchmark 统一参数（`size: auto`），不等同于在插件里选 2K/4K 档位；
- 插件面板与 Web 不做实时同步，Web 跑完需在插件里重开工作台/切换用例；
- 结果图以 data URI 读入浏览器，4K 图较多时页面内存占用较高；
- 删除用例不可恢复。

## 10. 用例从哪来（三种来源）

| 来源 | 适合 | 怎么做 |
|---|---|---|
| PS 冻结 | 真实画布、要带选区/资产 | 插件「开发者工作台 ▸ 基准 ▸ 冻结当前画面并运行」 |
| 导入用例包 | 换机器、把别人的用例搬过来 | 侧栏「导入用例包」，选 `.json` |
| 导入提示词包 | 一批提示词做横向对比（文字/海报/写实…） | 侧栏「导入提示词包…」，选 `.txt/.md`，填尺寸 |

**提示词包格式**（两种都认）：

```
[A1 单物+属性]
输入：一只橘猫坐在木窗台上，午后侧光。
判定：□ 只有一只猫 □ 在窗台
```

或者一行一条提示词（自动跳过 `#` 注释、`===` 分隔线、`判定：` 行）。

导入时：

- 每条提示词建一个**文生图用例**，底图是所选尺寸的纯白画布（文生图不会把它当参考图发出去）；
- 已存在的提示词按哈希自动跳过，重复导入不会长出一堆副本；
- `输入图：` / `提问：` 这类**看图题**不会建用例（缺真实底图），会提示跳过了哪几条；
- 一次最多 80 条。

## 11. 找用例 / 出报告

- 侧栏顶部搜索框：按标题、功能名、提示词片段过滤，计数显示「命中/总数」。
- 结果区右上「导出 CSV」：当前用例的全部结果一行一条，含耗时、尺寸、评分、备注、
  `seed`、工作流指纹、预设名、错误信息；带 BOM，Excel 双击打开不乱码。
