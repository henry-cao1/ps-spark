### P0-1 编辑域本地 inpaint 1:1 回贴

**目的**：验证蒙版、导出区域、结果落图三者在真实文档里不错位。

1. 设置 ▸ 本地 ComfyUI，选中「Klein 4B 局部重绘」预设（节点角色应为 `PROMPT / INPUT / MASK / OUTPUT`）
2. 打开 3000×2000、300dpi 文档，用矩形选框工具框出 600×400，记下左上角坐标
3. 编辑 ▸ 重绘 ▸ 局部重绘，模型选本地预设，提示词写「换成一只橘猫」，运行
4. 结果出来后，在图层面板确认新层位置，放大到 100% 看边缘
5. 再打开一张 72dpi 文档，重复步骤 2–4

**通过标准**

- [x] 结果层左上角与选区坐标一致，宽高为 600×400（允许 ±1px）
- [x] 100% 视图下选区边缘无接缝、无硬边、无半透明描边
- [x] 选区外的像素没有被改动（可用历史记录或图层对比）
- [x] 图层面板无 `pssparkSelClip*` 通道残留（通道面板检查）
- [x] `Cmd+Z` 一次即可撤销整次落图
- [x] 72dpi 文档下位置与尺寸同样正确（排除分辨率换算错误）

**附加**：运行中点「取消」，确认选区通道被清理、没有半张图落进文档。

3. 云端任务运行中点单条取消；另开一轮点「取消全部」
4. 先排一条慢的本地任务，再排一条快的云端任务（看「待落图」）
5. 本地任务轮询中关掉 ComfyUI（制造失败）
