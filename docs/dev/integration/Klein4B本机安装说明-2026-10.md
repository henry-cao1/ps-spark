## 常见问题

**启动报 `CLIPLoaderGGUF` 没有 `flux2` 类型**
ComfyUI 版本偏旧。在 ComfyUI 界面里把 `type` 换成 `qwen_image` 试；
或更新 ComfyUI 到最新版（`cd ~/ComfyUI && git pull`）。

**黑图 / 噪点**
MPS 精度问题，启动加 `--bf16-vae`；16GB 内存紧张时用 `--cpu-vae`。

**生成中崩溃**
内存不足。关掉 PS 和浏览器多余标签；把尺寸降到 768×768 或 512×512 再试。

**速度慢**
M4 基础款 1024×1024 约 1–2 分钟正常；4 步不要加步数。
