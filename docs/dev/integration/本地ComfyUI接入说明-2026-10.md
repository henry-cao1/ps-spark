# 本地 ComfyUI 接入说明（2026-10）

> 生图页可以直接切到本机 ComfyUI：提示词提交给本地工作流，结果图回贴 PS。  
> 只支持文生图；相似图等带参考图的功能请切回云端模型。

---

## 1. 准备

1. 启动 ComfyUI，确认地址（默认 `http://127.0.0.1:8188`）。
   - Windows：双击项目根目录的 `Start-ComfyUI.bat`
     （本机用直接双击；装在另一台机器上就双击时带 `-lan`，或命令行 `Start-ComfyUI.bat -lan -open`）
     它会自动找 ComfyUI 目录、找 Python（便携包/venv/系统都认），找不到会提示改 `COMFY_DIR`
   - Mac：双击项目根目录的 `Start-ComfyUI.command`
     （跨机用 `-lan`，换端口 `-port 8189`，自开浏览器 `-open`，只看检测结果 `-check`；
     首次双击若被系统拦，右键 → 打开 一次即可）
2. 在 ComfyUI 里调好一张图的工作流。
3. 用 **Workflow ▸ Export (API)** 导出 JSON（不是普通 Save）。
4. 工作流至少包含：
   - 一个 **CLIPTextEncode** 作为正向提示词；
   - 一个 **SaveImage**（输出节点）；
   - 可选 **EmptyLatentImage**（插件会按尺寸设置替换 `width/height`）。
   - 负面提示词节点建议把标题命名为 `Negative`，插件会自动跳过它。

---

## 2. 配置（一条工作流 · 可绑多台机器）

设置 ▸ **本地 ComfyUI**。

**为什么仍是一个模型一条工作流**：工作流里写死了模型文件名和架构节点（Flux 的
`EmptySD3LatentImage` 与 SDXL 的 `CheckpointLoaderSimple` 不通用），换模型必须换工作流，
这个省不掉。能省的是「换机器」：同一条工作流可以填多个地址，不必为每台机器复制一遍。

| 项 | 说明 |
|---|---|
| 模型预设 | 下拉切换；名称显示在生图/编辑的模型下拉里（`本地 · 名称`） |
| 新增 / 复制 / 删除 | 复制用于「同机不同工作流」（如文生图 + 重绘两条） |
| 名称 | 建议带机器与用途，如「Klein 4B（Mac）」「SDXL-Inpaint（Win）」 |
| 主地址 | 默认 `http://127.0.0.1:8188`；跨机填对方 IP |
| 其他机器地址 | 一行一个。同一套工作流装在多台机器时填这里，运行时自动选第一台在线的 |
| 能力 | 文生图 / 参考图 / 局部重绘 / 分割 —— 决定它出现在哪些功能的模型下拉里 |
| 透明通道 | 支持 / 不支持 / 未知。选「不支持」时，拆图自动改走纯色底 + 抠色 |
| 工作流 JSON | 「导入 JSON…」选文件，比粘贴稳（UXP 文本框会截断） |
| 高级 | 提示词节点 ID（留空自动）、步数 / CFG / 重绘幅度（留空则用工作流里的值） |
| 导出 / 导入预设 | 换电脑时搬配置，不用重配 |

**节点角色**：工作流里把节点标题（右键 ▸ Rename）改成
`PROMPT` / `NEGATIVE` / `INPUT` / `MASK` / `SIZE` / `OUTPUT`，
插件按角色注入提示词、图片、蒙版、尺寸，不用记节点 id。没改标题也能按节点类型自动识别；
重绘类工作流必须有 `LoadImage`（标题 `INPUT`）和 `LoadImageMask`（标题 `MASK`），否则会明确报错。

**多机**：主地址 + 其他机器地址（一行一个）。运行时先探测 `/system_stats`，选第一台在线的；
某台离线会顺延到下一台，15 秒内复用探测结果。前提是这些机器装的是同一套模型文件；
文件不一致时以「检测全部」的逐台结果为准。

**内置模板**：「添加内置模板」一次建 3 条，新机器只要改地址：

| 模板 | 能力 | 说明 |
|---|---|---|
| Klein 4B 文生图 | 文生图 | 纯文字，4 步 / CFG 1 |
| Klein 4B 参考图 | 参考图（i2i） | 单图参考，`LoadImage` 作 INPUT，denoise 0.6 |
| Klein 4B 局部重绘 | 局部重绘 | `LoadImage` + `LoadImageMask`，denoise 0.85 |

> Klein 4B 是基础生成模型，不是指令型 inpaint 模型。上面两条重绘/参考图模板能把
> **链路**跑通（图片与蒙版上传、尺寸 1:1、提示词注入），但「把物体换成红色花瓶」这类
> 指令跟随效果有限；要质量请换 SDXL-Inpaint / Flux Fill 等工作流，模板结构照抄即可。

**能力会自动校正**：勾了「参考图 / 局部重绘 / 分割」但工作流里没有
`LoadImage` / `LoadImageMask` / 分割节点时，读取预设时会把虚标能力剔除，
避免下拉里选中一个根本跑不了的预设。想恢复某项能力，先把对应节点加进工作流。

粘贴整段 JSON 在 UXP 文本框里容易截断，几 KB 的工作流建议直接用「导入 JSON…」。
导入时会顺手校验：普通 Save 导出的工作流（含 `nodes`/`links`）会被拒绝并提示改
用 Workflow ▸ Export (API)；找不到 `SaveImage` 输出节点会标红。

点「测试连接」会保存表单并逐台请求 `/system_stats`，同时用 `/object_info` 粗查
每台机器上工作流引用的模型文件在不在，缺了会直接列出来。

## 3. 使用

参数区末尾的「模型」一行（生图在「候选张数」下方，编辑在参数卡片底部）：

- **跟随设置**：用设置 ▸ 模型分配里的模型；
- **云端模型**：本次临时覆盖；
- **本地 · 预设名**：走该机器的工作流。能力不匹配的预设会灰掉，点一下会说明缺什么能力。

选择后正常输入提示词、选尺寸、点运行。结果图和云端模型一样回贴图层、进历史。

编辑域选本地预设时：插件把「导出区域图 + 选区蒙版」上传到 ComfyUI，按 `INPUT` / `MASK`
两个角色注入，结果按选区 1:1 回贴；重绘幅度取预设里填的值（没填默认用工作流里的 denoise）。

---

## 4. 限制

- **参考图**：生成域支持 **1 张**（相似图等单图参考，需「参考图」能力的预设）；多图拼合（>1 张）仍拒绝，
  因为角色模型只有一个 `INPUT` 槽。编辑域的「图片 + 蒙版」不受此限。
- **本地分割（拆图 segment）**未实现：勾了分割但没有分割节点，会被能力校正自动剔除。
- 工作流里的 checkpoint / LoRA / 采样器是固定的，插件不会按模型名切换——要换就换预设。
- 只替换正向提示词、seed、尺寸、步数/CFG/重绘幅度；负面提示词要工作流里有 `NEGATIVE` 节点才会填。
- 生成期间关闭 PS 或断开 ComfyUI 会中断，需要重跑。

## 5. 常见问题

**连接失败**

- ComfyUI 是否启动、端口是否一致；
- 远程 ComfyUI 需要能访问该地址（本机默认只监听 127.0.0.1）。

**CORS / 跨域报错**  
启动 ComfyUI 时加：

```bash
python main.py --enable-cors-header "*"
```

**「工作流里找不到正向提示词节点」**

- 工作流用的不是 `CLIPTextEncode`（例如 SDXL 的 `CLIPTextEncodeSDXL`），  
  在设置里直接填该节点的数字 ID。

**「ComfyUI 执行失败」**  
看 ComfyUI 控制台的节点报错，常见是缺模型文件、LoRA 名称不匹配、显存不足。

**结果尺寸不对**  
工作流里如果有 `EmptyLatentImage`，插件会按生图页选的尺寸替换；  
如果工作流用别的尺寸节点，需要在工作流里固定。

## 6. 本机实测（2026-10 · Mac mini M4 16GB）

Klein 4B Q8 GGUF + Qwen3-4B Q6 编码器，4 步 euler/simple：

| 项         | 结果                           |
| --------- | ---------------------------- |
| 1024×1024 | 86s（首次含模型加载）                 |
| 768×768   | 约 50s                        |
| 出图质量      | 写实风格可用；4 步下细节笔画偏硬（如腿部边缘发黑）   |
| 内存        | 加载后常驻约 12GB，同时开 PS 会开始用 swap |

复验命令（不需要开 PS，走的就是插件那套 `callComfyUI` / `downloadResultToEntry`）：

```bash
NODE_PATH=<node_modules> \
  node bench/test-comfy-live.cjs --size=768x768
```

ComfyUI 没启动时脚本直接 SKIP，不会算失败。

## 7. Web 测试台里的限制

`comfy` 已进模型目录，但只在**文生图**用例上可勾选：

- 其他用例（相似图/局部重绘/拼合…）上「本地 ComfyUI」是虚线灰态，点了会说明原因；
- 强行调接口会返回 400，不会静默跑出一张与输入无关的图；
- 想用测试台批量测本地模型，先在 PS 里冻结一条文生图用例。

## 8. 验收清单（PS 里走一遍）

前置：ComfyUI 已启动（浏览器能开 `http://127.0.0.1:8188`），插件面板是含「导入 JSON…」的版本。

**配置**

1. 设置 ▸ 本地 ComfyUI ▸「导入 JSON…」选 `ComfyUI-Klein4B-workflow.json`  
   → 状态行应显示「已导入 … 8 个节点 · 提示词节点 4」。
2. 点「测试连接」→「连接正常 ✓」。

**跑一张**

1. 生图页 → 参数区「生图张数」下面那行模型 → 选「本地 ComfyUI」。
2. 提示词写一句、尺寸 1024×1024、张数 1 → 运行。
3. 进度条先「提交到本地 ComfyUI」，再「本地 ComfyUI 生成中 Ns」，60–90s 出图；  
   结果卡出现候选 → 点插入 → 生成图层；历史 Tab 多一条。

**逐条对风险点**

| 检查      | 怎么看                      | 不对时                             |
| ------- | ------------------------ | ------------------------------- |
| 不是黑图/噪点 | 看候选缩略图                   | 启动参数 `--bf16-vae` 换 `--cpu-vae` |
| 尺寸跟所选一致 | 结果卡尺寸 = 1024×1024        | 工作流尺寸节点不是 `EmptySD3LatentImage` |
| 提示词真进画面 | 换成「蓝色玻璃球」这类强特征词再跑        | 提示词节点 ID 填错，看设置里的节点号            |
| seed 随机 | 同提示词连跑两次，两张不同            | 工作流里 seed 不是数字类型                |
| 多张串行    | 张数填 2，约 2×90s，进度逐张推进     | ——                              |
| 断连不卡死   | 关掉 ComfyUI 再点运行，应很快报连接失败 | 地址/端口不对                         |
| 取消有效    | 生成中点取消，不留半截图             | ——                              |

**出问题看这里**：设置 ▸ 诊断与数据 ▸「记录调试日志」默认是开的，跑完看

```
~/Library/Application Support/Adobe/UXP/PluginsStorage/PHSP/26/External/com.psspark.ps.assistant/PluginData/psspark_debug.log
```

里面会有 `xhr POST http://127.0.0.1:8188/prompt`、`comfy: prompt_id=…`、  
`comfy: 完成，耗时 Ns`。报错时段最后几十行基本能定位是没连上、工作流不认，还是出图超时。

## 9. 透明通道与拆图

拆图逐层生成时，**只有真支持 alpha 的模型才能直接出透明底**；不支持却申请透明，
拿到的是「棋盘格被画进像素」的伪透明——看着像透明，实际是 RGB，后面选主体、做蒙版全对不准。

插件按模型能力自动分流：

| 模型透明能力 | 判定来源 | 拆图行为 |
|---|---|---|
| 支持（native） | 本地预设「透明通道」选「支持」；云端仅 `gpt-image-2.5` / `gpt-image-2.5-flare` / `gpt-image-2` | 申请 `background: transparent`，按透明通道分层 |
| 不支持（none） | 本地预设里声明 | 提示词改成纯洋红 `#FF00FF` 底，并禁止画格子；出图后魔棒取底 → 反选 → 建图层蒙版，再用蒙版取原图像素 |
| 未知（unknown） | 其余云端模型 | 按不支持处理，走纯色底路径 |

判断依据是「宁可抠色，不要伪透明」：抠色失败可修（调容差、手动魔棒），
伪透明失败不可修（像素里画着格子，还把色调带偏）。

**不自动擦棋盘格**：周期方块纹理和主体边缘会互相污染，擦完比不擦更糟。

拆图产物始终是「图层 + 蒙版」，不是「带 alpha 的 PNG」——蒙版能反复改，alpha 烘进去就回不来了。

## 10. 生图任务队列

点一次「生图」就入队，可以连着点多次，任务按顺序跑，不会互相顶掉。
运行中按钮会变成「＋ 加入队列」，仍然可以继续点（不会灰掉）。队列条出现在面板底部、
结果区下方，一行一个任务：

| 状态 | 含义 | 能做什么 |
|---|---|---|
| 等待 | 排在前面任务之后 | 点 × 直接取消（还没开始，不会占 API） |
| 运行中 | 正在生成（云端最多 2 条同时跑，本地 1 条） | 点 × 标记取消；只有这一条在跑时立刻中断请求，多路并发时让它自然结束、不落图 |
| 待落图 | 图已生成，排队等写进画布 | 点 × 取消这一条，不会写进画布 |
| 完成 | 已出图并写入图层 | —— |
| 失败 | 有原因（Key、断连、工作流报错…） | 重新点生成即可 |
| 已取消 | 主动取消 | —— |

- **并行规则**：云端 2 路并发；本地 ComfyUI 1 路（单实例只能串行）；编辑类 1 路（要动画布与选区）。
  队列标题会显示「运行 2 · 等待 1」。
- **落图按入队顺序**：生成允许乱序完成，但「谁先写进画布」由队列顺序决定（落图中的行显示「待落图」）。
  这样三张图层叠放顺序和点击顺序一致，不会因为某张快就插到前面。
- **快照隔离**：任务保存点击那一刻的提示词、参数、参考图，之后改界面不会影响已排队的任务。
- **换模型不影响队列**：本地和云端可以混排，按各自队列顺序跑。
- **生图域和编辑域都排队**，拆图不排队（拆图是独立三步流程，自己管并发）。
- **编辑任务的选区会被记住**：入队时把当前选区复制成临时通道（`pssparkQ…`），执行前还原，
  跑完自动删除。排队后你可以继续换选区做别的，任务执行时改的仍是入队时的区域。
- **编辑任务要求原文档还是当前文档**：换文档会跳过并说明原因，避免改到别的画布上。
- 结束后最多保留 20 条历史（界面显示最近 8 条），点「清空已完成」可立即清理。
